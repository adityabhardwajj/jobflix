## 🎯 Quick Start

1. **Backend**: `cd backend && npm install && npm run server`
2. **Frontend**: `cd frontend && npm install && npm run dev`
3. **Database**: Set up MongoDB and update `.env`
4. **Seed**: Run `node seeder.js` to populate sample data
